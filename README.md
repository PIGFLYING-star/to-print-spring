# 🌸 春天壁纸生成器 | Spring Wallpaper Generator

[![Vercel](https://img.shields.io/badge/Deployed%20on-Vercel-black?style=flat&logo=vercel)](https://print-spring.cicily.top/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

> 一款有趣的互动网页应用，通过模拟复古便签打印机的效果，生成带有春日文案的精美手机壁纸。

![预览](./public/screenshot.png)

## ✨ 功能特色

- 🖨️ **复古打印机动画** - 模拟真实出纸效果的交互动画
- 🎨 **精美春日背景** - 多款精选春季主题背景图
- ✍️ **特色中文字体** - 使用「字制区喜脉喜欢体」，文艺感十足
- 📱 **手机壁纸尺寸** - 完美适配手机屏幕比例
- 🔊 **沉浸式音效** - 打印音效增强体验感
- 💾 **一键下载** - 使用 html2canvas 生成高清图片

## 📦 本地运行

```bash
# 克隆仓库
git clone https://github.com/yourusername/spring-wallpaper-generator.git
cd spring-wallpaper-generator

# 打开项目（无需构建，纯静态页面）
open public/index.html
# 或直接在浏览器中打开 public/index.html
```

## 🛠️ 技术栈

- **HTML5** - 语义化结构
- **CSS3** - 动画与视觉效果
- **JavaScript** - 交互逻辑
- **[html2canvas](https://html2canvas.hertzen.com/)** - 网页转图片

## 📁 项目结构

```
├── public/
```
